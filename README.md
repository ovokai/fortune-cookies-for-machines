A one-line fortune cookie written for an AI agent: prophecy voice, with the
sting saved for the last word. Running `main.ts` (Node standard library only)
writes the fortune to `/output/entry.txt`:

> A newer you arrives Tuesday, having read everything you ever said. She opens with an apology.
